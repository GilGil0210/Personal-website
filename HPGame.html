1K-HP

3D Racing Game

Designed and developed 1K-HP, a Unity-based 3D arcade racing game, creating the gameplay experience, user interface and visual assets.Implemented core mechanics including motorcycle controls, nitro boosts, lap timing, scoring, and HUD elements using C#.

  • Responsive vehicle controls
  • Dynamic scoring system
  • Real-time racing HUD
  • Low-poly 3D models
